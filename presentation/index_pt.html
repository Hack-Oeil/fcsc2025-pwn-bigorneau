Bigorneau

Muitas vezes procuramos obter shellcodes com restrições invulgares, seja de tamanho, alfanuméricas, etc. Aqui, experimentamos uma nova restrição invulgar para um shellcode x64: só é permitido utilizar 6 valores de bytes diferentes (ou seja, len(set(shellcode)) <= 6)!
